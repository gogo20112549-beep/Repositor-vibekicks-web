# VIBEKICKS - Premium Sneakers & Streetwear E-Commerce Platform

![VIBEKICKS Preview](assets/logo.png)

A modern, highly responsive, and aesthetically stunning e-commerce web platform designed for premium sneakers and streetwear enthusiasts.

---

## 🌟 Key Features

- **Dynamic Hero & Showcase**: Interactive banners with high-resolution sneaker showcases and animated call-to-actions.
- **Product Catalog & Category Filtering**: Filter shoes seamlessly by brand (Nike, Adidas, Jordan, Puma, etc.) and category.
- **Interactive Shopping Cart**: Add to cart, adjust quantities, view subtotal, and responsive cart drawer.
- **Search & Discovery**: Real-time product search by name, model, and category.
- **Image Gallery & Product Showcase**: Dedicated gallery views with responsive grid layouts.
- **Modern Responsive Design**: Glassmorphism UI, smooth gradients, micro-interactions, and mobile-friendly navigation.

---

## 🛠️ Technology Stack

- **Frontend**: HTML5, Semantic Elements
- **Styling**: Vanilla CSS3 (Custom Design System, Flexbox, CSS Grid, CSS Variables)
- **Typography**: Google Fonts (Outfit)
- **Logic**: Vanilla JavaScript (ES6+ Modules & Event-Driven Architecture)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/vibekicks-web.git
cd vibekicks-web
```

### 2. Run locally
You can open `index.html` directly in any modern browser, or use a local development server:
```bash
# Using VS Code Live Server extension or Python HTTP server:
python -m http.server 3000
# or with Node / npx:
npx serve .
```
